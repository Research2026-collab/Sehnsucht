# Sehnsucht as Democratic Praxis and Resource in Civic Adult Education

Presentation materials and supplementary resources accompanying the
contribution **"Sehnsucht as Democratic Praxis and Resource in Civic
Adult Education"**, presented at **Scuola Democratica 2026 (Rome)**.

## Overview

This repository provides educational and academic materials exploring
*Sehnsucht* (longing) as an analytical, reflexive and methodological
resource for civic adult education.

The repository currently contains:

-   Presentation website
-   Five supplementary information sheets (PDF)
-   Project landing page
-   Additional presentation slides (to be added)
