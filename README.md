# Sehnsucht landing page

Static GitHub Pages landing page for the session **“Sehnsucht” as Democratic Praxis and Resource in Civic Adult Education**.

## Upload to GitHub

1. Upload the complete contents of this folder to the root of the `Sehnsucht` repository.
2. Keep the folders `assets` and `downloads` unchanged.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the branch `main` and the folder `/ (root)`, then save.

The page will normally be available at:

`https://research2026-collab.github.io/Sehnsucht/`
